# Code signing policy

LUDARYX is an open-source Windows application distributed from the official repository at https://github.com/gustavosdus/LUDARYX and licensed under the MIT License.

## SignPath

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

If accepted into the SignPath Foundation open-source program, only official LUDARYX release artifacts built from this repository will be submitted for signing.

## Project roles

Current maintainer: Gustavo José da Silva (@gustavosdus).

- Committer: Gustavo José da Silva
- Reviewer: Gustavo José da Silva
- Signing approver: Gustavo José da Silva

Pull requests from contributors must be reviewed before merge. This section will be updated if additional trusted maintainers are added.

## Release process

Official release artifacts are produced from the source and build scripts in this repository, checked by GitHub Actions, validated for version consistency, and published through GitHub Releases. Signing requests require manual approval.
