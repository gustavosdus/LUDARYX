## Captura

- Grave em 1920×1080 ou superior.
- Use a interface real da versão publicada.
- Evite mostrar dados pessoais, nomes de usuário, caminhos locais, notificações ou chaves de API.
- Use jogos/capas apenas como demonstração visual da biblioteca; não apresente o projeto como afiliado às marcas.
- Para cortes de interface, prefira movimentos de 2–4 segundos e não acelere tanto a ponto de esconder o comportamento do produto.
