PERGUNTAS FREQUENTES

O que você precisa saber sobre o LUDARYX.

Compatibilidade, segurança, launchers originais, controles e funcionamento da biblioteca.

O que é o LUDARYX?

Um launcher unificado, gratuito e open source para Windows que reúne jogos instalados de diferentes plataformas em uma única biblioteca visual.

Quais plataformas são suportadas?

Steam, Epic Games, GOG, Xbox/Microsoft Store, EA app, Ubisoft Connect, Battle.net e Riot Client, além de jogos adicionados manualmente.

Ele substitui Steam, Epic ou os outros clientes?

Não. O LUDARYX organiza e inicia os jogos. O cliente original ainda pode ser necessário para licença, atualização, autenticação ou recursos online.

É gratuito e open source?

Sim. O código-fonte é publicado no GitHub sob licença MIT.

Possui telemetria?

A versão 1.2.2 não possui telemetria própria. Preferências, biblioteca e estatísticas locais permanecem no computador, conforme descrito na documentação de privacidade.

Quais controles funcionam?

Controles Xbox compatíveis com XInput, DualSense, teclado e mouse.

Em quais versões do Windows funciona?

O projeto é voltado para Windows 10/11 x64 e usa .NET 8.

Como as atualizações são distribuídas?

As releases oficiais ficam no GitHub. O atualizador usa o instalador publicado e valida SHA-256 antes da instalação automática.
