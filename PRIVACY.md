# Privacy Notice — LUDARYX 1.0.1

This notice describes the current source build. It should be reviewed whenever networking features change.

## Local data
LUDARYX stores library preferences, play counts, hidden/favorite items, manual metadata, API credentials protected with Windows DPAPI, cached metadata, and downloaded artwork locally on the user's computer.

## Network requests
When metadata/artwork enrichment is enabled, LUDARYX may contact third-party services such as Steam, GOG, Wikidata/Wikipedia, PCGamingWiki, IGDB, and SteamGridDB. Those services receive ordinary network information such as the user's IP address and request metadata under their own privacy policies.

## No project telemetry in this build
LUDARYX 1.0.1 does not include first-party analytics or telemetry that uploads the user's game library to a LUDARYX-operated server.

## Future updater
A future automatic updater must be documented here before release. Prefer version checks that do not transmit the user's game library, play history, API keys, or other unnecessary personal data.

## User control
Users can remove the application's local settings/cache from their Windows user profile after closing LUDARYX. Do not document a deletion path here unless it is verified against the exact release build.
