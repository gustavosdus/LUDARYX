# Configurações

As preferências do launcher são salvas em:

`%LOCALAPPDATA%\UnifiedGameLauncher\settings.json`

A opção **Aplicativos ocultos** grava os identificadores `Platform:Id` dos itens que não devem aparecer na biblioteca.

Isso não desinstala, remove ou altera os jogos nos clientes originais. Apenas controla a exibição no LUDARYX.
