## Post técnico — comunidades open source

Apresentando o LUDARYX 1.2.0, um launcher unificado para Windows desenvolvido em .NET 8/WPF e publicado sob licença MIT.

O projeto detecta bibliotecas de diferentes plataformas, mantém jogos manuais, suporta capas personalizadas, metadados, filtros, duplicatas, estatísticas locais, modo TV e navegação por teclado/XInput/DualSense.

O foco da 1.2.0 foi consistência de tema, navegação por controle, fluxo de abertura de jogos e organização interna do código. O MainWindow também foi dividido em arquivos parciais para facilitar manutenção.

Código: https://github.com/gustavosdus/LUDARYX
